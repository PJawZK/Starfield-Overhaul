# Starfield-Overhaul

Experimental Starfield overhaul project focused on testing how far the game can be pushed toward:

- genuinely alien and diverse worlds
- less repetitive locations
- meaningful space exploration
- player-controlled planetary/lunar flight
- terrain-scale ship gameplay such as crater and canyon runs
- hidden asteroid, moon, and terrain-integrated bases

This is a **fun experimental project**, not a commitment to a production release.

Research, reverse-engineering evidence, and capability probes live in [`PJawZK/Starfield-RE`](https://github.com/PJawZK/Starfield-RE). Reverse-engineering tooling remains in `rea_JZ-Fork`.

Production-oriented code, scripts, assets, build tooling, and playable experiments can move here once the relevant capability has been established well enough to justify implementation.
